## แผนทดสอบ: VAD กับการตัดท่อนเสียงสำหรับ Typhoon Whisper

### 1. คำถามที่ต้องตอบ

| #   | คำถาม                                                                                | ใช้ตัดสินอะไร                     |
| --- | ------------------------------------------------------------------------------------ | --------------------------------- |
| Q1  | ตัดท่อนตรงช่วงหยุดพูด (แบบ B) แม่นกว่าปล่อยให้ Whisper ตัดทุก 30 วินาทีตายตัวหรือไม่ | จะใช้แบบ B หรือไม่ใช้ VAD เลย     |
| Q2  | `--vad` แบบกรองทิ้งแล้วต่อกัน (แบบ A ที่ใช้อยู่) ทำให้แย่ลงกับเสียงยาวด้วยหรือไม่    | ยืนยันว่าควรเลิกใช้แบบ A          |
| Q3  | ถ้าไม่กรองช่วงเงียบทิ้ง Whisper จะแต่งข้อความในช่วงเงียบหรือเสียงรบกวนมากแค่ไหน      | จะทิ้งช่วงเงียบยาวหรือไม่         |
| Q4  | แต่ละแบบใช้เวลาและ VRAM เท่าไร                                                       | ใช้งานจริงได้หรือไม่              |
| Q5  | timestamp ละเอียดพอให้กดคำอ้างอิงแล้วเลื่อนไปบรรทัดที่ตรงได้ไหม                      | ฟีเจอร์ในหน้าเว็บยังใช้ได้หรือไม่ |

### 2. ข้อมูลทดสอบ

ใช้ 79 ประโยคจาก FLEURS ภาษาไทยที่ดึงไว้แล้วใน `data/eval/w16/` (16.1 นาที มีเฉลย) มาต่อกันเป็นไฟล์ยาวสองแบบ โดยบันทึกเวลาเริ่ม-จบของทุกประโยคและทุกช่วงกับดักไว้ใน `timeline.json`

| ไฟล์                        | วิธีสร้าง                                                                                                                                                                                   | จำลองสถานการณ์                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **L1: มีช่วงหยุดและกับดัก** | ต่อประโยคตามลำดับ เว้นช่วงเงียบสุ่ม 0.3–1.0 วินาที (กำหนด seed ให้สร้างซ้ำได้) และแทรกกับดัก 6 จุด: เงียบสนิท 20–30 วินาที ×3, เสียงรบกวนเบา (pink noise ~-40 dBFS จาก ffmpeg) 20 วินาที ×3 | สายโทรศัพท์ที่มีช่วงเงียบ หรือห้องเรียนที่มีช่วงพัก |
| **L2: พูดต่อเนื่อง**        | ต่อประโยคเว้นช่องแค่ 0.1–0.2 วินาที ไม่มีกับดัก                                                                                                                                             | ข่าวช่อง 9 ที่ VAD หาช่วงเงียบไม่เจอ                |

### 3. การตั้งค่าที่จะเทียบ

| รหัส    | โมเดล        | วิธี                                                                   | หมายเหตุ                                        |
| ------- | ------------ | ---------------------------------------------------------------------- | ----------------------------------------------- |
| **C1**  | Typhoon q8_0 | ทั้งไฟล์ ไม่ใช้ VAD                                                    | Whisper ตัดทุก 30 วินาทีตายตัว                  |
| **C2**  | Typhoon q8_0 | ทั้งไฟล์ + `--vad`                                                     | แบบ A                                           |
| **C3**  | Typhoon q8_0 | แบบ B: ตัดตรงช่วงหยุดพูด และทิ้งเฉพาะช่วงเงียบ ≥2 วินาทีที่ VAD มั่นใจ | ตัวเลือกที่แนะนำ                                |
| **C3k** | Typhoon q8_0 | แบบ B แต่ไม่ทิ้งอะไรเลย                                                | แยกผลของ "การทิ้งช่วงเงียบ" ออกจาก "การตัดท่อน" |
| **C4**  | turbo q8_0   | ทั้งไฟล์ ไม่ใช้ VAD                                                    | ค่าอ้างอิง                                      |
| **C5**  | turbo q8_0   | ทั้งไฟล์ + `--vad`                                                     | ค่าที่ใช้งานจริงตอนนี้                          |

ทุกแบบใช้ `-mc 0` และ `-l th` เหมือนกัน

**เงื่อนไขสำคัญ:** C3/C3k ต้องเรียกโค้ดตัดท่อนตัวเดียวกับที่ worker จะใช้จริง ไม่ใช่ใช้สคริปต์แยก จึงต้องย้ายตรรกะการตัดตามพลังงานเสียงจาก eval/vad-test/make.ts ไปเป็นฟังก์ชันใน `src/` ก่อน แล้วให้ทั้ง worker และสคริปต์ทดสอบเรียกฟังก์ชันเดียวกัน

### 4. ตัวชี้วัด

| ตัวชี้วัด                                                                           | วิธีคำนวณ                                                                                            | ตอบคำถาม                              |
| ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **CER**                                                                             | เทียบข้อความเฉลยทั้งไฟล์กับผลทั้งไฟล์ (ตัดช่องว่างและเครื่องหมาย ใช้ตัวคำนวณเดียวกับ `score.py`)     | Q1, Q2                                |
| **แยกชนิดความผิด S / D / I**                                                        | ย้อนเส้นทาง Levenshtein: S = ตัวอักษรถูกแทน, D = ตกหล่น, I = แทรกเกิน                                | D สูง = เสียงหาย (GIGO), I สูง = หลอน |
| **ตัวอักษรในช่วงกับดัก**                                                            | นับตัวอักษรของ segment ที่เวลาทับช่วงกับดักเกิน 50% (เฉพาะ L1)                                       | Q3                                    |
| **รอยตัดกลางคำ**                                                                    | นับรอยตัด (ของ C3 หรือหน้าต่าง 30 วินาทีของ C1) ที่ตกอยู่ภายในช่วงของประโยค เทียบกับ `timeline.json` | Q1                                    |
| **ความยาว segment เฉลี่ย** และ **% ประโยคที่มี segment เริ่มห่างไม่เกิน ±2 วินาที** | จาก timestamp ของผล                                                                                  | Q5                                    |
| **เวลา** และ **VRAM สูงสุด**                                                        | จับเวลา และอ่าน `nvidia-smi` ทุก 1 วินาที                                                            | Q4                                    |

### 5. เกณฑ์ตัดสิน (ตั้งไว้ก่อนดูผล)

1. **เลือก C3** ถ้า CER ของ C3 ≤ C1 และ D ไม่สูงกว่า C1 เกิน 0.5 จุด และตัวอักษรในช่วงกับดักน้อยกว่า C1
2. **ถ้า C3k ดีกว่า C3** (CER ต่ำกว่าและการหลอนไม่ต่างกันมาก) ให้ใช้แบบไม่ทิ้งช่วงเงียบ
3. **ถ้า C1 ดีกว่า C3 ชัดเจน** ให้ใช้แบบไม่มี VAD แต่ต้องยอมรับ timestamp หยาบ 30 วินาที (ซึ่งไม่ผ่าน Q5)
4. **ถ้า C2 แย่กว่า C1** ให้ยืนยันว่าเลิกใช้ `--vad` แบบ A ในทุกโหมด
5. **ถ้าโมเดลเดียวกันต่างกันไม่ถึง 0.5 จุด CER** ถือว่าไม่ต่างกัน ให้เลือกแบบที่ง่ายกว่าหรือมี timestamp ดีกว่า

### 6. ตรวจด้วยการฟังเสียงจริง (คนทำ)

ตัวเลขข้างบนมาจากเสียงอ่านที่สะอาด จึงต้องเช็กกับเสียงจริงด้วย:

- ใช้ `data/vad-test/` กับ test/WB-IMF.M4A (ข่าวช่อง 9) และ src/lec_test.m4a (บรรยาย)
- คุณฟังท่อนที่ติดป้าย "ตัดกลางเสียงพูดต่อเนื่อง" ว่าตกกลางคำหรือไม่ และฟังโฟลเดอร์ `dropped/` ว่ามีคำพูดหลุดหรือไม่
- จดผลเป็น: ตัดดี / ตัดกลางคำ / มีคำพูดหลุด

### 8. ข้อจำกัดที่ต้องรู้

- FLEURS เป็นเสียงอ่านในห้องเงียบ ไม่ใช่สายโทรศัพท์ ผลกับสายของคุณแม่อาจต่างออกไป
- ช่วงเงียบและเสียงรบกวนเป็นของที่สร้างขึ้น ไม่ใช่เสียงสายจริง
- รันแบบละครั้งเดียว ความต่างที่น้อยกว่า ~0.5 จุด CER อาจเป็นแค่ความบังเอิญ
- เฉลยของ FLEURS เขียนตัวเลขเป็นเลขอารบิกและชื่อเป็นภาษาอังกฤษ ทำให้ CER ทุกแบบสูงขึ้นเท่ากัน ใช้เทียบกันได้ แต่ไม่ใช่ค่าความแม่นแบบสัมบูรณ์
