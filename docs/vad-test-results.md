# ผลทดสอบตามแผน `vad-test-plan.md`

ตัวเลขทั้งหมดอยู่ใน `eval/results.md` (สร้างโดย `eval/metrics.ts` จากผลดิบใน `data/eval/long/results/`)

## สรุปการตัดสินตามเกณฑ์ข้อ 5

| เกณฑ์ | ผล |
|---|---|
| 1. เลือก C3 (ตัดท่อนเอง + ทิ้งเงียบ ≥2 วินาที) | ✅ CER 16.6% (L1) / 15.3% (L2) เทียบ C1 25.5% / 27.1% และ turbo (C4) 19.4% / 20.2% |
| 2. C3k (ไม่ทิ้งช่วงเงียบ) ดีกว่า C3 หรือไม่ | ❌ แย่กว่ามาก (CER 38.1% / 27.0%) ตัวอักษรเกิน (I) 2,654 เทียบ 660 Whisper แต่งข้อความในช่วงเงียบ → ต้องทิ้งช่วงเงียบยาว |
| 3. C1 ดีกว่า C3 ชัดเจน | ไม่เป็นจริง |
| 4. C2 แย่กว่า C1 → เลิก `--vad` แบบกรองทิ้ง | ✅ CER 36.9% / 37.7% ข้อความหายราว 30% (D 2,792) ใช้กับ turbo ก็แย่ลง (C5 แย่กว่า C4) → ถอด `--vad` ออกจากทุกโหมด |

## ค่าเริ่มต้นที่ตั้งไว้

`WHISPER_MODEL=models/ggml-typhoon-large-v3-q8_0.bin`, `WHISPER_MODE=chunked`, `CHUNK_SECONDS=25`, `DROP_SILENCE_SECONDS=2`, `KEEP_SILENCE=false`

## ข้อจำกัด / สิ่งที่ยังไม่รู้

- ตัวชี้วัด "รอยตัดกลางประโยค" แยกไม่ออกระหว่างจุดหยุดกลางประโยคกับตัดกลางคำ ต้องฟังตรวจเอง (ขั้น 6 ของแผน)
- timestamp ของ C3 หยาบกว่า turbo: ท่อนเฉลี่ย 13–20 วินาที, ประโยคเริ่มตรง ±2 วินาที 71% (L1) / 39% (L2) เทียบ turbo 92–100% (บนข่าว Typhoon ให้ segment ละเอียดกว่านี้ ~4 วินาที จึงไม่ใช่ว่าไม่มี timestamp เสมอไป)
- ความเร็ว: C3 ≈ 19–28 นาทีต่อเสียง 1 ชั่วโมง (turbo ≈ 5 นาที) การถอดทั้งไฟล์ (C1) ช้ากว่า 3–4 เท่าและยังไม่ทราบสาเหตุ (สมมติฐาน: temperature fallback ยังไม่ได้ตรวจ)
- เสียงทดสอบเป็นเสียงอ่านสะอาดและเว้นช่วงเงียบที่สร้างขึ้น รันแบบละครั้ง ยังไม่ใช่สายโทรศัพท์จริง
- ตัวคำนวณ CER ของ FLEURS รุ่นแรก (`eval/score.py`) ตัดสระ/วรรณยุกต์ทิ้ง คำนวณใหม่แล้วในไฟล์ results.md ผลต่างไม่ถึง 0.2 จุด ข้อสรุปเดิมไม่เปลี่ยน
