# TranscribeAI — สรุปโปรเจกต์สำหรับ session ใหม่

อัปเดตล่าสุด: 2026-10-13 · ยังไม่มี commit ใด ๆ (ไฟล์ทั้งหมดอยู่ใน working tree)

## 1. เป้าหมายและข้อกำหนด

เว็บแอปส่วนตัวถอดเสียงและสรุปบันทึกเสียงภาษาไทย (เช่น สายคุยกับคุณแม่ → "แม่ขอให้ทำอะไร / ถามอะไร / ผมรับปากอะไร") ที่ **รันในเครื่อง ไม่ส่งข้อมูลออกนอกเครื่อง (PDPA)** ใช้ GPU ล้วน ไม่ดึง CPU เพิ่ม

- เครื่อง: Lenovo LOQ 15IRH8 (i5-12450h, RTX 2050 **4 GB VRAM**, RAM 15.8 GB), Windows 11
- มือถือ: Galaxy A22 5G เข้าเว็บผ่าน Tailscale
- เป็นโปรเจกต์วิชา AI (ส่งโปรแกรม + สไลด์; เกณฑ์: กำหนดปัญหา, เตรียมข้อมูล, ประยุกต์/ปรับปรุง AI, **ประเมินผลด้วยตัวชี้วัด**, นำเสนอ)
- ผู้ใช้สื่อสารเป็นภาษาไทย ชอบให้อธิบายตัวย่อ/รหัสให้ชัด (เคยงงกับ VAD, CER, C1–C5, L1/L2)

## 2. สถาปัตยกรรม

```
อัปโหลด m4a → ffmpeg (wav 16k mono) → [chunker: VAD + พลังงานเสียง] → Typhoon Whisper (GPU)
  → ลบเสียงทันที → cleanSegments (ตัดวนซ้ำ) → Typhoon 4B / llama.cpp (GPU) แบ่งช่วง 8 นาที
  → JSON สรุป + ตรวจคำอ้างอิงกับ transcript (verify) → SQLite → หน้าเว็บ
```

| ไฟล์ | หน้าที่ |
|---|---|
| `src/index.ts` | Elysia: API + หน้าเว็บ ฟังหลายที่อยู่ (`HOST=100.84.39.20,127.0.0.1`) |
| `src/worker.ts` | คิว 2 รอบ (ถอดเสียงทุกงาน แล้วสรุปทุกงาน), `transcribe()`, `summarize()`, `cfg` |
| `src/chunker.ts` | ตัดท่อนเสียง: VAD (`whisper-vad-speech-segments`) + ตัดตามพลังงานเสียงที่จุดเบาสุดเมื่อช่วงพูดยาว >25 วินาที, ทิ้งเงียบ ≥2 วินาที |
| `src/whisper.ts` | เรียก `whisper-cli` เป็นชุด, `parseWhisperJson` (ต่อไบต์ UTF-8 ที่ถูกตัดกลางตัวอักษร, ตัด `�`) |
| `src/proc.ts` | `run()` / `rm()` |
| `src/prompt.ts` | prompt สรุป, JSON schema, `cleanSegments`/`collapseRepeats`, `verify` (ตรวจคำอ้างอิง), `dedupe` |
| `src/db.ts` | SQLite ตารางเดียว `recordings` (กู้งานค้างเมื่อเปิดใหม่) |
| `public/index.html` | หน้าเดียว: อัปโหลด, รายการ, ความคืบหน้า (poll 2.5 วินาที), ผลสรุป, กดคำอ้างอิงเลื่อนไป transcript |
| `docs/vad-test-plan.md`, `docs/vad-test-results.md` | แผนและข้อสรุปการทดสอบ VAD |
| `eval/*`, `eval/vad-test/*` | สคริปต์วัดผลและ `results*.md` (อยู่ใน git; ข้อมูลเสียง/ผลดิบอยู่ใน `data/eval/`, `data/vad-test/` ซึ่ง gitignore; รันสคริปต์จาก root เช่น `bun eval/metrics.ts`) |

ไฟล์ใหญ่ที่ไม่อยู่ใน git: `bin/whisper` (whisper.cpp b5454 CUDA 12.4), `bin/llama` (llama.cpp b11574 CUDA 12.4), `models/` (ดูข้อ 4)

## 3. ค่าเริ่มต้นปัจจุบัน (`.env.example`; `.env` จริงตั้งแค่ `HOST` และ `PORT`)

`WHISPER_MODEL=models/ggml-typhoon-large-v3-q8_0.bin`, `WHISPER_MODE=chunked`, `WHISPER_LANG=th`, `CHUNK_SECONDS=25`, `DROP_SILENCE_SECONDS=2`, `KEEP_SILENCE=false`, `LLM_CTX=8192`, `CHUNK_MINUTES=8`, `LLM_TEMP=0.2`, `KEEP_AUDIO_DAYS=0`

รันด้วย `bun run start` (ต้องเปิด Tailscale ก่อน เพราะฟังที่ IP `100.84.39.20`) ตอนนี้เซิร์ฟเวอร์เปิดอยู่ที่ `http://localhost:3000` และมือถือเข้าได้ที่ `http://loqstation:3000` (ชื่อเต็ม `loqstation.tail1ecf67.ts.net`) · มีเซิร์ฟเวอร์ดูผล VAD ค้างที่พอร์ต 3100 (`eval/vad-test/serve.ts`) ปิดได้

## 5. ผลทดสอบสำคัญ

คำศัพท์: CER = อัตราผิดระดับตัวอักษร (S ถอดผิด / D ตกหล่น / I เกิน); L1 = ไฟล์ยาว 19 นาทีที่ต่อจาก FLEURS ไทย 79 ประโยค + เงียบ/เสียงรบกวนกับดัก; L2 = 16 นาทีพูดต่อเนื่อง; C1–C5 = การตั้งค่าที่เทียบ (ดู `docs/vad-test-plan.md`)

| config | CER L1 / L2 | เวลา L1 |
|---|---|---|
| **C3** Typhoon ตัดท่อนเอง + ทิ้งเงียบ ≥2 วินาที | **16.6% / 15.3%** | 357 วินาที |
| **C4** turbo ทั้งไฟล์ ไม่ VAD | 19.4% / 20.2% | 84 วินาที |
| C1 Typhoon ทั้งไฟล์ | 25.5% / 27.1% | 1,485 วินาที |
| C2 Typhoon + `--vad` | 36.9% / 37.7% (ข้อความหาย ~30%) | 817 |
| C3k ไม่ทิ้งเงียบ | 38.1% / 27.0% (หลอนในช่วงเงียบ I พุ่ง 4 เท่า) | 524 |
| C5 turbo + `--vad` | 25.6% / 23.4% | 120 |

ข้อสรุป: **เลิก `--vad` แบบกรองทิ้งทุกโหมด**; ห้ามส่งช่วงเงียบยาวให้ Whisper; เก็บ C3 (แม่นสุด) และ C4 (เร็ว/timestamp ละเอียด/หลายภาษา) FLEURS สั้น 79 ประโยค: turbo 16–17%, Typhoon 12–13% ตารางเต็ม `eval/results.md`, `eval/results-lang.md`

**ทดสอบ 3 ภาษา** (`test/TH.m4a EN.m4a ZH.m4a`, เฉลย `test/Text.txt`): Typhoon ใช้ได้เฉพาะไทย (เขียนอังกฤษ/จีนเป็นอักษรไทย แม้ตั้ง `-l`), turbo ถูกหมด (EN WER 0%, ZH CER 9.8%, TH 8.2%) และตรวจจับภาษาเองถูก; turbo ต่อท้ายคำหลอน `感谢观看`; Typhoon เขียนตัวเลขเป็นคำ (CER ไทยจึงสูงกว่า) และมีไบต์ UTF-8 ขาดบางตัว

## 6. ข้อค้นพบทางเทคนิคที่ควรจำ

- `-vmsd` ของ `whisper-vad-speech-segments` ไม่มีผล (ช่วงพูดต่อเนื่อง 66 วินาทีไม่ถูกแยก) จึงตัดเองตามพลังงานเสียง
- `--prompt` ศัพท์เฉพาะใช้ไม่ได้กับ `-mc 0`; `-mc 64`+prompt ทำให้ข้อความหาย 83%; `-nf` ทำให้วนซ้ำมากขึ้น
- ตัวคำนวณ CER ใน `eval/score.py` (รุ่นแรก) ตัดสระ/วรรณยุกต์ ใช้ `eval/metrics.ts` แทน
- `llama-cli` รุ่นใหม่เป็นโหมดแชทชน JSON grammar → ใช้ `llama-completion` + ChatML; ctx 8192 ใช้ VRAM ~3.6 GB (ctx 4096 ไม่พอสำหรับ 10 นาทีไทย ~5.5k token)
- ตัวตรวจ `verify` จับ "แต่งคำอ้างอิง" ได้ แต่จับ "จับคู่รายการกับคำพูดผิดบรรทัด" ไม่ได้

## 7. สิ่งที่ยังค้าง / ยังไม่ได้ทำ

**ต้องให้ผู้ใช้ทำ:** เปิด Windows Firewall พอร์ต 3000 สำหรับ Tailscale (มือถือเข้าได้แล้ว แสดงว่าทำแล้ว) · เปิดฟีเจอร์ Serve ใน Tailscale ถ้าต้องการ HTTPS · ตั้ง Power Plan ไม่ให้ NB sleep · ทดสอบอัดสายบน A22 กับสายจริงของคุณแม่ 3–5 สาย · ฟังตรวจท่อนที่ตัดใน `data/vad-test/` (ขั้น 6 ของแผน)

**งานโค้ด/ทดลองที่ยังไม่ได้ทำ:**
1. ตัดสินใจเรื่อง **การเลือกโมเดลตามภาษา** (ให้ turbo ตรวจภาษาก่อน: ไทย→C3, อื่น→C4, หรือใช้ C4 ทุกกรณี) และเพิ่มตัวกรองคำหลอนท้ายไฟล์ (`感谢观看`, "ขอบคุณที่รับชม", "Thanks for watching")
2. **ทดสอบให้ Qwen ช่วยแก้คำถอดเสียงที่ไม่สมเหตุสมผล** เทียบกับไม่ใช้ เพื่อดูว่าหลอนมากขึ้นหรือไม่ (ผู้ใช้ขอไว้ ยังไม่เริ่ม) แนวคิด: แก้ทีละบรรทัดโดยคงเวลา/จำนวนบรรทัด จำกัดสัดส่วนที่เปลี่ยน และเทียบ CER บน FLEURS/L1/L2
3. หาสาเหตุที่ถอดทั้งไฟล์ (C1) ช้ากว่าการตัดท่อน 3–4 เท่า (สมมติฐาน: temperature fallback ยังไม่ได้ตรวจ)
4. ขั้นสรุปภาษาอื่น (prompt ยังเป็นภาษาไทย), ทดสอบสรุปรวมหลังแก้ prompt "ห้ามอ้างถึงช่วงที่ N" (ยังไม่ได้รันซ้ำ)
5. อัปเดต `README.md` (ยังบอกว่าใช้ turbo + `--vad`) และบันทึกวิธีแปลง Typhoon เป็น ggml เป็นสคริปต์
6. ตัดสินใจ `KEEP_AUDIO_DAYS` หลังลองสายจริง · เปิดแอปอัตโนมัติตอนบูต (ไม่บังคับ)
7. **งานวิชา:** ทำสไลด์นำเสนอ; ชุดข้อมูลและตัวชี้วัดมีแล้ว (FLEURS ไทยแยกไฟล์สั้น, L1/L2, 3 ภาษา, CER/WER/S/D/I); ถามอาจารย์ว่า "ประยุกต์ใช้โมเดลสำเร็จรูป + ทดลองเปรียบเทียบ" นับได้หรือไม่ (ไม่มีการเทรนเอง; VRAM 4 GB ไม่พอ fine-tune)
8. ยัง **ไม่ commit** (ต้องระวังไม่ให้ไฟล์เสียง `test/*.m4a`, `bin/`, `models/`, `data/` ติด git; `.gitignore` ตั้งไว้แล้ว)

## 8. ข้อจำกัดที่ต้องบอกผู้ใช้เสมอ

ผลสรุปมาจาก AI ตรวจซ้ำในเรื่องสำคัญ (ตัวเลข วันที่ ชื่อ จำนวนเงิน) · ข้อมูลทดสอบเป็นเสียงอ่านสะอาด/เสียงห้องเรียนที่ยังไม่ใช่สายโทรศัพท์จริง · ไฟล์ทดสอบเล็ก ผลแกว่งได้ · การอัดเสียงคนอื่นควรแจ้งให้ทราบ
